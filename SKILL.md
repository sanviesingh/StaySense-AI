# Topic-Aligned Website Skill

## Purpose
Make every part of a website feel connected to a single topic so the experience feels intentional, coherent, and relevant.

## When to Use
Use this skill when:
- the site has generic or mixed messaging
- pages contain unrelated wording, features, or placeholders
- you want the entire experience to reflect one theme such as hospitality, education, travel, health, or e-commerce

## Workflow
1. Define the core topic and audience.
   - Choose one clear theme.
   - Identify 3 to 5 key concepts that support that theme.

2. Audit the entire site.
   - Review the homepage, navigation, buttons, forms, cards, footer, and any supporting text.
   - Look for generic labels, irrelevant features, or off-topic copy.

3. Rewrite content around the topic.
   - Replace broad or neutral wording with topic-specific language.
   - Keep terminology consistent across all pages.
   - Make headings, descriptions, and calls to action reflect the same idea.

4. Align the visual language.
   - Use colors, icons, imagery, and styling that reinforce the topic.
   - Avoid visual elements that feel unrelated to the theme.

5. Remove or replace off-topic content.
   - Delete generic sections, unrelated examples, or placeholder text.
   - If something does not support the topic, change it or remove it.

6. Verify the result.
   - Check that every major page feels part of the same story.
   - Confirm that navigation, content, and design all reinforce the same topic.

## Decision Points
- If the topic is broad, narrow it into a few recurring themes instead of using many disconnected ideas.
- If content is already relevant but too generic, improve the wording rather than changing the structure.
- If a page still feels unrelated, either rewrite it fully or remove it from the experience.

## Quality Checklist
- Every major page supports the same topic.
- Navigation labels and page copy are consistent.
- Buttons, forms, and content blocks use topic-relevant language.
- The overall design and tone feel unified.
- No obvious generic or unrelated placeholder text remains.
